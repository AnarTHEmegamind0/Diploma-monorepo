# Phase 2: LabelImg ашиглан Label Хийх Заавар

## Зорилго

Цуглуулсан зураг бүр дээр бүтээгдэхүүнийг тэмдэглэж (bounding box), 
ямар бүтээгдэхүүн болохыг зааж өгөх. Үүнийг "labeling" гэнэ.

---

## LabelImg Суулгах

Terminal дээр:

```bash
# Virtual environment идэвхжүүлэх
source inventory_env/bin/activate

# LabelImg суулгах
pip install labelImg
```

---

## LabelImg Нээх

```bash
# LabelImg эхлүүлэх
labelImg data/raw data/labeled/labels --autosave
```

**Параметрүүд:**
- `data/raw` - Зургууд байгаа хавтас
- `data/labeled/labels` - Label файлууд хадгалах хавтас
- `--autosave` - Автоматаар хадгална

## Label Хийх Алхамууд

### Алхам 1: YOLO Format сонгох

1. Дээд menu-ээс **View** → **Auto Save mode** идэвхжүүлэх
2. Зүүн талын **Save** товчны доор **PascalVOC** гэж байвал дарж **YOLO** болгох

```
┌─────────────┐
│ PascalVOC   │  ← Үүн дээр дарна
├─────────────┤
│ YOLO        │  ← YOLO сонгоно ✓
│ CreateML    │
└─────────────┘
```

### Алхам 2: Classes файл тохируулах

LabelImg-д `data/raw` хавтас дотор `classes.txt` файл үүсгэх:

```bash
# classes.txt файл үүсгэх
cat > data/raw/classes.txt << 'EOF'
coca_cola
fanta
sprite
pepsi
lays
pringles
snickers
mars
water_bottle
milk
EOF
```

**Чухал:** Энэ дараалал `dataset.yaml` дахь дарааллтай яг адилхан байх ёстой!

### Алхам 3: Bounding Box зурах

1. **W** товчлуур дарна (эсвэл зүүн талын "Create RectBox")
2. Бүтээгдэхүүн дээр хулганаар bounding box зурна
3. Class нэр сонгох цонх гарна

```
    Bounding box зурах:
    
    ┌─────────────────────────┐
    │                         │
    │   ┌─────────────┐       │
    │   │ ┌─────────┐ │       │   ← Энд эхлэх
    │   │ │  COCA   │ │       │
    │   │ │  COLA   │ │       │
    │   │ └─────────┘ │       │
    │   └─────────────┘       │   ← Энд дуусгах
    │                         │
    └─────────────────────────┘
```

### Алхам 4: Class сонгох

```
┌─────────────────────────┐
│ Select object label     │
├─────────────────────────┤
│ coca_cola          ← 0  │  ← Сонгоно
│ fanta              ← 1  │
│ sprite             ← 2  │
│ pepsi              ← 3  │
│ ...                     │
└─────────────────────────┘
```

### Алхам 5: Дараагийн зураг руу шилжих

- **D** товчлуур - Дараагийн зураг
- **A** товчлуур - Өмнөх зураг
- **Ctrl+S** - Хадгалах (autosave байгаа бол хэрэггүй)

---

## Товчлол (Keyboard Shortcuts)

| Товчлуур | Үйлдэл |
|----------|--------|
| W | Шинэ bounding box зурах |
| D | Дараагийн зураг |
| A | Өмнөх зураг |
| Ctrl+S | Хадгалах |
| Del | Сонгосон box устгах |
| Ctrl+U | Зураг хавтас солих |
| Ctrl+R | Label хавтас солих |

## Label Файлын Формат (YOLO)

Зураг бүрт `.txt` файл үүснэ:

```
# coca_cola_001.txt файлын агуулга:
0 0.5 0.5 0.3 0.4
│ │   │   │   │
│ │   │   │   └── height (normalized 0-1)
│ │   │   └────── width (normalized 0-1)
│ │   └────────── y_center (normalized 0-1)
│ └────────────── x_center (normalized 0-1)
└──────────────── class_id (0 = coca_cola)
```

**Жишээ:** Нэг зурагт 3 бүтээгдэхүүн байвал:
```
0 0.25 0.50 0.15 0.30
1 0.50 0.50 0.15 0.30
2 0.75 0.50 0.15 0.30
```

## Сайн Label vs Муу Label

### ✅ Сайн label:

```
┌─────────────────────┐
│   ┌───────────┐     │   Box нь бүтээгдэхүүнийг
│   │ ┌───────┐ │     │   нягт хүрээлсэн
│   │ │ COCA  │ │     │
│   │ │ COLA  │ │     │
│   │ └───────┘ │     │
│   └───────────┘     │
└─────────────────────┘
```

### ❌ Муу label:

```
┌─────────────────────┐
│ ┌─────────────────┐ │   Box хэтэрхий том
│ │                 │ │   (хоосон зай их)
│ │    ┌───────┐    │ │
│ │    │ COCA  │    │ │
│ │    │ COLA  │    │ │
│ │    └───────┘    │ │
│ │                 │ │
│ └─────────────────┘ │
└─────────────────────┘
```

### ❌ Бас муу:

```
┌─────────────────────┐
│       ┌──────┐      │   Box хэтэрхий жижиг
│       │COCA  │      │   (бүтээгдэхүүний хэсэг
│    ┌──┴──────┴──┐   │    гадуур үлдсэн)
│    │    COLA    │   │
│    └────────────┘   │
└─────────────────────┘
```

## Зургуудаа Хуулах

Label хийсний дараа зургуудаа `data/labeled/images/` руу хуулна:

```bash
# Зургуудыг хуулах
cp data/raw/*.jpg data/labeled/images/
cp data/raw/*.png data/labeled/images/
cp data/raw/*.jpeg data/labeled/images/
```

---

## Шалгах

### Label файлууд үүссэн эсэх:

```bash
# Label файлуудын тоо
ls data/labeled/labels/*.txt 2>/dev/null | wc -l

# Зургийн тоо
ls data/labeled/images/*.jpg 2>/dev/null | wc -l
```

**Хүлээгдэж буй үр дүн:** Хоёр тоо тэнцүү байна!

### Label файлын агуулга шалгах:

```bash
# Эхний 5 label файлыг харах
head -3 data/labeled/labels/*.txt | head -20
```

## Түгээмэл Асуудлууд

### 1. "No images found"

**Шийдэл:** Зургийн хавтас замаа шалгана

**Шийдэл:** 
1. YOLO format сонгосон эсэхээ шалгана
2. Label хавтас бичих эрхтэй эсэх

### 3. Classes харагдахгүй

**Шийдэл:** `classes.txt` файл зураг хавтаст байгаа эсэх
