# Phase 2: Зураг Цуглуулах Заавар

## Зорилго

YOLOv8 model сургахын тулд бүтээгдэхүүний зураг цуглуулах. 
Зураг олон байх тусам model илүү сайн сурна.

---

## Шаардлага

- **Нийт зураг:** Хамгийн багадаа 300 зураг (500+ илүү сайн)
- **Бүтээгдэхүүн бүр:** 30-50 зураг
- **Төрөл:** JPG эсвэл PNG формат
- **Хэмжээ:** 640x480 - 1920x1080 пиксел (гар утасны зураг тохирно)

## Зураг Авах Заавар

### 1. Хаанаас зураг авах вэ?

**Хамгийн сайн:** Бодит дэлгүүрт очиж зураг авах
- CU, GS25, Номин зэрэг дэлгүүрүүд
- Супермаркетын тавиур
- Хүнсний дэлгүүр

**Бас боломжтой:** Гэртээ бүтээгдэхүүн авчирч зураг авах

### 2. Ямар өнцгөөс зураг авах вэ?

Бүтээгдэхүүн бүрийг янз бүрийн өнцгөөс:

```
    Дээрээс       Урдаас        Хажуугаас
       ↓            ↓              ↓
    ┌─────┐      ┌─────┐       ┌─────┐
    │ === │      │     │       │    /│
    │ === │      │ COCA│       │   / │
    │ === │      │COLA │       │  /  │
    └─────┘      └─────┘       └─────┘
```

### 3. Ямар гэрэлтүүлэгтэй вэ?

- Цонхны гэрэл (natural light)
- Дэлгүүрийн гэрэл (fluorescent)
- Бүдэг гэрэл (dim)
- Flash ашиглаагүй

### 4. Ямар зайнаас зураг авах вэ?

```
ОЙРХОН (30см)     ДУНД (1м)        АЛСААС (2м+)
┌───────────┐    ┌───────────┐    ┌───────────┐
│           │    │   ┌───┐   │    │ ┌─┐ ┌─┐   │
│  ┌─────┐  │    │   │   │   │    │ └─┘ └─┘   │
│  │COCA │  │    │   │   │   │    │ ┌─┐ ┌─┐   │
│  │COLA │  │    │   └───┘   │    │ └─┘ └─┘   │
│  └─────┘  │    │           │    │           │
└───────────┘    └───────────┘    └───────────┘
```

### 5. Нэг зурагт хэдэн бүтээгдэхүүн байж болох вэ?

**Нэг бүтээгдэхүүн:** Ойр зайнаас, тодорхой харагдана
**Олон бүтээгдэхүүн:** Дэлгүүрийн тавиур, бодит нөхцөл

## Зургийг Компьютерт Хуулах

### iPhone-оос:

1. USB кабелиар холбоно
2. Finder/Photos app нээнэ
3. Зургуудаа сонгоод `data/raw/` руу хуулна

### Android-оос:

1. USB кабелиар холбоно
2. DCIM/Camera хавтас нээнэ
3. Зургуудаа `data/raw/` руу хуулна

### AirDrop (Mac):

1. Зургуудаа сонгоод AirDrop-оор илгээнэ
2. Downloads-оос `data/raw/` руу зөөнө

## Зураг Байгаа Эсэхийг Шалгах

Terminal дээр:

```bash
# Зургийн тоог шалгах
ls data/raw/*.jpg 2>/dev/null | wc -l
ls data/raw/*.png 2>/dev/null | wc -l
ls data/raw/*.jpeg 2>/dev/null | wc -l

# Нийт зургийн тоо
ls data/raw/ | wc -l
```

**Хүлээгдэж буй үр дүн:** 300+ зураг

## Сайн Зураг vs Муу Зураг

### ✅ Сайн зураг:

- Бүтээгдэхүүн тодорхой харагдана
- Focus сайн, бүдэг биш
- Бүтнээрээ харагдана (таслагдаагүй)
- Гэрэлтүүлэг хангалттай

### ❌ Муу зураг:

- Бүдэгдсэн (blurry)
- Хэт харанхуй
- Бүтээгдэхүүн бүрэн харагдахгүй
- Гар дарсан

## Түгээмэл Асуултууд

**Q: Хэдэн зураг хангалттай вэ?**
A: 300+ зураг хамгийн бага. 500-1000 зураг илүү сайн үр дүн өгнө.

**Q: Зургийн чанар хэр чухал вэ?**
A: Маш чухал! Бүдэг зураг model-д муу нөлөөлнө.

**Q: Нэг зурагт олон бүтээгдэхүүн байж болох уу?**
A: Тийм! Энэ бодит дэлгүүрийн нөхцөлд илүү ойр.

**Q: Бүтээгдэхүүнийг өөрчилж болох уу?**
A: Тийм, `models/configs/dataset.yaml` файлыг засна.
